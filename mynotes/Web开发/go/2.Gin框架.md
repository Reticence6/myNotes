# Gin

## 介绍

Gin是一个Go编写的轻量级http web框架， 运行速度非常快

Gin擅长Api接口的高并发

## 环境搭建

1. 创建项目并初始化Go模块

   ```shell
   mkdir gin-quickstart && cd gin-quickstart
   go mod init gin-quickstart
   ```

2. 下载并安装Gin

   ```go
   go get -u github.com/gin-gonic/gin
   ```

3. 编写代码

   ```go
   package main
   
   import "github.com/gin-gonic/gin"
   
   func main() {
     router := gin.Default()
     router.GET("/ping", func(c *gin.Context) {
       c.JSON(200, gin.H{
         "message": "pong",
       })
     })
     router.Run() // 默认监听 0.0.0.0:8080
   }
   ```

4. 运行API服务，在浏览器中访问 http://localhost:8080/ping 即可

   ```go
   go run main.go
   ```

5. Gin结合net/http使用

   - 如果需要用net/http包中的常量表示相应码，同时导入即可

   ```go
   package main
   
   import (
     "github.com/gin-gonic/gin"
     "net/http"
   )
   
   func main() {
     router := gin.Default()
     router.GET("/ping", func(c *gin.Context) {
       c.JSON(http.StatusOK, gin.H{
         "message": "pong",
       })
     })
     router.Run()
   }
   ```

6. 配置golang程序的热加载

   - 使用工具  http://github.com/gravityblast/fresh

   ```go
   go install github.com/pilu/fresh@latest
   // 之后运行时输入fresh即可
   fresh
   ```

### c.JSON()

```go
type Article struct {
	// 结构体字段小写开头时，会被 Go 标记为「包私有」（仅当前包可访问），
	// 而 Gin 的 JSON 序列化依赖reflect反射包，无法跨包访问私有字段，因此序列化结果为空；
	// 大写开头的字段是「公有」的，能被反射访问，才能正常序列化。
	Title   string `json:"title"`
	Desc    string `json:"desc"`
	Content string `json:"content"`
}

func main() {
	// 创建一个默认的路由引擎
	router := gin.Default()

	// 返回JSON
	router.GET("/json", func(c *gin.Context) {
		c.JSON(http.StatusOK, map[string]interface{}{
			"success": true,
			"msg":     "json",
		})
	})
	router.GET("/json2", func(c *gin.Context) {
		c.JSON(http.StatusOK, gin.H{
			"success": true,
			"msg":     "json2",
		})
	})
	router.GET("/json3", func(c *gin.Context) {
		// 实例化结构体时用指针不是语法强制要求，
		// 但在 Gin（及大部分 Go 开发场景）中是推荐写法
		// 核心优势是「避免拷贝开销」+「支持修改原实例」+「符合 Gin 的序列化优化逻辑」。
		a := &Article{
			Title:   "Title",
			Content: "Content",
			Desc:    "Desc",
		}

		c.JSON(http.StatusOK, a)
	})

	// 启动一个web服务
	router.Run(":8000")
}
```

### c.JSONP

`JSONP`（JSON with Padding）是一种**非官方的跨域数据交互协议**，本质不是新技术，而是利用`<script>`标签不受浏览器同源策略限制的特性，实现跨域获取数据的 “hack 技巧”—— 注意：它和 JSON 无关，只是数据格式用 JSON，核心是 “动态脚本注入 + 回调函数”。

JSONP 是 “前端跨域的权宜之计”，解决了早期 AJAX 跨域的问题，但现代开发中，CORS（后端配置`Access-Control-Allow-Origin`等响应头）是更规范、安全的选择。

```go
// 返回JSONP
// http://127.0.0.1:8000/jsonp?callback=xx
// xx({"title":"Title","desc":"Desc","content":"Content"});
router.GET("/jsonp", func(c *gin.Context) {

  a := &Article{
    Title:   "Title",
    Content: "Content",
    Desc:    "Desc",
  }

  c.JSONP(http.StatusOK, a)
})
```

### 模板放在不同目录里面的配置方法

如果页面比较多，需要分组

Gin 框架中如果不同目录下面有同名模板的话我们需要使用下面方法加载模板

注意：定义模板的时候需要通过 define 定义名称

`templates/admin/index.html`

`<!-- 相当于给模板定义一个名字 define end 成对出现-->`

```html
{{ define "admin/index.html"}}
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <h2> admin {{.title}} </h2>
</body>
</html>
{{ end }}
```

注意： 如果模板在多级目录里面的话需要这样配置 r.LoadHTMLGlob("templates/**/**/*") /**表示目录

```go
func main() {
	// 创建一个默认的路由引擎
	router := gin.Default()
	// 配置模版文件
	// /**表示一个目录
	router.LoadHTMLGlob("templates/**/*")

	// 加载html，渲染模版
	// 默认
	router.GET("/news", func(c *gin.Context) {
		news := &Article{
			Title:   "title",
			Content: "content",
			Desc:    "desc",
		}

		c.HTML(http.StatusOK, "default/news.html", gin.H{
			"title": "news data",
			"news":  news,
		})
	})
	router.GET("/goods", func(c *gin.Context) {

		c.HTML(http.StatusOK, "default/goods.html", gin.H{
			"title": "goods data",
		})
	})
	router.GET("/", func(c *gin.Context) {
		c.HTML(http.StatusOK, "default/index.html", gin.H{
			"title": "首页",
		})
	})

	// 后台
	router.GET("/admin/news", func(c *gin.Context) {
		news := &Article{
			Title:   "title",
			Content: "content",
			Desc:    "desc",
		}
		c.HTML(http.StatusOK, "admin/news.html", gin.H{
			"title": "后台news data",
			"news":  news,
		})
	})
	router.GET("/admin", func(c *gin.Context) {
		c.HTML(http.StatusOK, "admin/index.html", gin.H{
			"title": "后台首页",
		})
	})

	// 启动一个web服务
	router.Run(":8000")
}
```

### 基本语法

1. <code v-pre>{{.}}</code> 输出数据

   - 模板语法都包含在<code v-pre>{{</code>和<code v-pre>}}</code>中间，其中<code v-pre>{{.}}</code>中的点表示当前对象。
   - 当我们传入一个结构体对象时，我们可以根据.来访问结构体的对应字段。

2. 注释 <code v-pre>{{/* a comment */}}</code>

3. 变量

   - 我们还可以在模板中声明变量， 用来保存传入模板的数据或其他语句生成的结果。

   ```html
   <!-- 定义变量 -->
   {{ $t := .title}}
   <br>
   <h4>
       {{$t}}
   </h4>
   ```

4. 移除空格

   - 有时候我们在使用模板语法的时候会不可避免的引入一下空格或者换行符， 这样模板最终渲染出来的内容可能就和我们想的不一样，
   - 这个时候可以使用<code v-pre>{{-</code>语法去除模板内容左侧的所有空白符号， 使用<code v-pre>-}}</code>去除模板内容右侧的所有空白符号。

   ```html
   {{-.Name -}}
   ```

5. 比较函数

   | 运算符 | 含义                         |
   | :----- | :--------------------------- |
   | `eq`   | 如果 `arg1 == arg2` 则返回真 |
   | `ne`   | 如果 `arg1 != arg2` 则返回真 |
   | `lt`   | 如果 `arg1 < arg2` 则返回真  |
   | `le`   | 如果 `arg1 <= arg2` 则返回真 |
   | `gt`   | 如果 `arg1 > arg2` 则返回真  |
   | `ge`   | 如果 `arg1 >= arg2` 则返回真 |

7. range

   - Go 的模板语法中使用 range 关键字进行遍历， 有以下两种写法， 其中 pipeline 的值必须是数组、切片、字典或者通道。

   ```html

   <ul>

    <ul>

       <li>{{$key}} -- {{$value}}</li>
       {{else}}
       <li>切片中没有数据</li>
       {{end}}
   </ul>
   ```

## 中间件

Gin 框架允许开发者在处理请求的过程中，加入用户自己的钩子（Hook）函数。这个钩子函

数就叫中间件， 中间件适合处理一些公共的业务逻辑， 比如登录认证、 权限校验、 数据分页、

记录日志、耗时统计等。

通俗的讲：中间件就是匹配路由前和匹配路由完成后执行的一系列操作

### 路由中间件

- Gin 中的中间件必须是一个 gin.HandlerFunc 类型， 配置路由的时候可以传递多个 func 回调函数，最后一个 func 回调函数前面触发的方法都可以称为中间件

  ```go
  router.GET("/middleware", func(c *gin.Context) {
    fmt.Println("aaa")
  }, func(c *gin.Context) {
    c.String(200, "中间件")
  })
  ```

- ctx.Next()调用该请求的剩余处理程序

  - 中间件里面加上 ctx.Next()可以让我们在路由匹配完成后执行一些操作。
  - 比如我们统计一个请求的执行时间。

  ```go
  func initMiddleware(c *gin.Context) {
  	start := time.Now().UnixNano()
  	fmt.Println("1-我是一个中间件-initMiddleware")
  
  	// 调用该请求的剩余处理程序
  	c.Next()
  
  	// 终止后面的程序，但是该函数后面的会执行完，一般不会用
  	//c.Abort()
  
  	fmt.Println("2-我是一个中间件-initMiddleware")
  	end := time.Now().UnixNano()
  
  	fmt.Println(end - start)
  }
  
  func main() {
  	// 创建一个默认的路由引擎
  	router := gin.Default()
  
  	router.GET("/middleware", initMiddleware, initMiddlewareTwo, func(c *gin.Context) {
  		fmt.Println("这是一个首页")
  		// time.Sleep(time.Second)
  		c.String(200, "中间件")
  	})
  
  	// 启动一个web服务
  	router.Run(":8000")
  }
  ```

- 一个路由配置多个中间件的执行顺序

  - 执行顺序：
    - initMiddlewareOne--1-执行中中间件
    - initMiddlewareTwo--1-执行中中间件
    - 执行路由里面的程序
    - initMiddlewareTwo--2-执行中中间件
    - initMiddlewareOne--2-执行中中间件

  ```go
  func initMiddleware(c *gin.Context) {
  	start := time.Now().UnixNano()
  	fmt.Println("1-我是一个中间件-initMiddleware")
  
  	// 调用该请求的剩余处理程序
  	c.Next()
  
  	// 终止后面的程序，但是该函数后面的会执行完，一般不会用
  	//c.Abort()
  
  	fmt.Println("2-我是一个中间件-initMiddleware")
  	end := time.Now().UnixNano()
  
  	fmt.Println(end - start)
  }
  
  func initMiddlewareTwo(c *gin.Context) {
  	fmt.Println("1-我是一个中间件-initMiddlewareTwo")
  
  	// 调用该请求的剩余处理程序
  	c.Next()
  
  	fmt.Println("2-我是一个中间件-initMiddlewareTwo")
  }
  ```

- c.Abort()--（了解）

  - Abort 是终止的意思， c.Abort() 表示终止调用该请求的剩余处理程序
  - 该中间件剩余的部分还会执行完，但是该中间件之后的函数都不会执行

## Cookie

### 介绍

https://gin-gonic.com/zh-cn/docs/examples/cookie/

-  HTTP 是无状态协议。简单地说，当你浏览了一个页面，然后转到同一个网站的另一个页面， 服务器无法认识到这是同一个浏览器在访问同一个网站。 每一次的访问， 都是没有任何关系的。 如果我们要实现多个页面之间共享数据的话我们就可以使用 Cookie 或者 Session 实现
- Cookie 是存储于访问者计算机的浏览器中。可以让我们用同一个浏览器访问同一个域名的时候共享数据。
- Cookie 能实现的功能
  - 保持用户登录状态
  - 保存用户浏览的历史记录
  - 猜你喜欢，智能推荐
  - 电商网站的加入购物车

### 设置和获取 Cookie

设置 Cookie

```go
c.SetCookie(name, value string, maxAge int, path, domain string, secure, httpOnly bool)
```

- 第一个参数 key
- 第二个参数 value
- 第三个参数 过期时间，如果只想设置 Cookie 的保存路径而不想设置存活时间， 可以在第三个参数中传递 nil，如果想删除可直接设置为-1
- 第四个参数 cookie 的路径
- 第五个参数 Domain 作用域，本地调试配置成 localhost , 正式上线配置成域名
- 第六个参数是 secure ，当 secure 值为 true 时，cookie 在 HTTP 中是无效，在 HTTPS 中才有效
- 第七个参数 httpOnly， 是微软对 COOKIE 做的扩展。 如果在 COOKIE 中设置了“httpOnly”属性，则通过程序（JS 脚本、applet 等）将无法读取到 COOKIE 信息，防止 XSS 攻击产生

获取 Cookie

```go

```

## Session

### Session 简单介绍

session 是另一种记录客户状态的机制，不同的是 Cookie 保存在客户端浏览器中，而 session保存在服务器上。

### Session 的工作流程

当客户端浏览器第一次访问服务器并发送请求时，服务器端会创建一个 session 对象，生成一个类似于 key,value 的键值对，然后将 value 保存到服务器 将 key(cookie)返回到浏览器(客户)端。浏览器下次访问时会携带 key(cookie)，找到对应的 session(value)。

### Gin 中使用 Session

Gin 官方没有给我们提供 Session 相关的文档， 这个时候我们可以使用第三方的 Session 中间件来实现

https://github.com/gin-contrib/sessions

gin-contrib/sessions 中间件支持的存储引擎：cookie、memstore、redis、memcached、mongodb

- 安装 session 包

  ```shell
  go get github.com/gin-contrib/sessions
  ```

- 在实际项目中定义数据库模型注意以下几点：

  - 结构体的名称必须首字母大写 ，并和数据库表名称对应。例如：表名称为 user 结构体名称定义成 User，表名称为 article_cate 结构体名称定义成 ArticleCate

### 事务处理

事务处理可以用来维护数据库的完整性，保证成批的 SQL 语句要么全执行，要么全不执行

#### 禁用事务

为了确保数据一致性，GORM 会在事务里执行写入操作（创建、更新、删除）。如果没有这方面的要求，您可以在初始化时禁用它，这将获得大约 30%+ 性能提升。

```go
func init() {
	dsn := "root:123456@tcp(127.0.0.1:3306)/learning2?charset=utf8mb4&parseTime=True&loc=Local"
	DB, err = gorm.Open(mysql.Open(dsn), &gorm.Config{
		QueryFields: true, // 打印SQL
		// SkipDefaultTransaction: true, // 禁用事务
	})

	if err != nil {
		fmt.Println(err)
	}
}
```

#### 事务

```go
func (con UserController) Index2(c *gin.Context) {
	// 开始事务
	tx := models.DB.Begin()
	// 抛出异常
	defer func() {
		if r := recover(); r != nil {
			// 遇到错误，回滚事务
			tx.Rollback()
			con.error(c)
		}
	}()

	// 在事务中执行一些db操作（从现在开始，应该使用 tx，而不是 db）
	// 张三给李四转账
	u1 := models.User{Id: 5}
	tx.Find(&u1)
	u1.Age = u1.Age - 1
	if err := tx.Save(&u1).Error; err != nil {
		tx.Rollback()
		con.error(c)
		return
	}
	// panic("异常")

	u2 := models.User{Id: 6}
	tx.Find(&u2)
	u2.Age = u2.Age + 1
	if err := tx.Save(&u2).Error; err != nil {
		tx.Rollback()
		con.error(c)
		return
	}

	// 提交事务
	tx.Commit()

	// 转账成功
	con.success(c)

}
```
